## C2-1–C2-6 architecture and staging clarification

- **C2-1 / compressed-prefix erasure:** Whole-token byte scans are insufficient because FTS5 leaf pages compress shared prefixes. The legacy NONE regression scans `canarytokenprefix`, distinct suffixes `alphaunique` / `betaunique`, interior token fragments and full terms in main `.sqlite`, every extant `.sqlite-wal` / `.sqlite-shm`, and each value of `evidence_fts_data`, `idx`, `content`, `docsize`, `config`. Checked WAL TRUNCATE is still required. These are current managed-file erasure guarantees, not backup/snapshot/media erasure.
- **C2-2 / separate-file two-phase protocol:** Registry DB and Repo DB are separate SQLite files. Step 1 commits Registry reservation ID, five-minute lease, allocation and monotonic per-repository `epoch_counter`; `reservation_epochs` associates that epoch with the durable reservation without changing the existing reservation layout. Step 2 writes evidence and commits `reservation_id` with Repo `repository_fence.last_committed_epoch` in the same Repo transaction. Step 3 finalizes Registry quota. A still-live reservation is rejected as `RESERVATION_FENCED_OFF` if its epoch is superseded in Registry or not greater than Repo's committed watermark. This augments, rather than replaces, registry-before-repo mutex serialization. It is recoverable two-phase accounting, not an atomic distributed transaction or two-phase-commit coordinator.
- **C2-3 / continuing-process recovery:** Explicit `reconcileQuota()` works without restart and is invoked on admission and foreground sync. It tallies the sum of actually committed `evidence.retained_bytes` in every Repo DB, including sealed namespaces. Expired or demonstrably dead same-host reservations are released; absent Repo commits contribute no bytes, and committed Repo evidence is preserved/accounted independently of reservation removal. Unexpired live or foreign-host reservations remain conservative pending allocations. The continuing-process regression kills a writer after Repo COMMIT, reconciles on the original store, and reaps an expired no-commit lease. No background scheduler is introduced.
